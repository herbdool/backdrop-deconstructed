#Backdrop AJAX Framework

AJAX is the de facto standard for having the web browser interact with
the server without requiring a full page refresh. The term is an
acronym for Asynchronous Javascript and XML, although it has come to
be widely used for any partial page refresh interaction. Backdrop's
specific version of it does not rely on XML at all. In earlier versions,
the Backdrop version of this was called AHAH, but as a community we chose
to start using standard terminology when Backdrop was released.

The primary use case for AJAX in Backdrop is within forms.
